# Subliminal Learning

This repository contains code for replicating experiments on subliminal learning in language models in the paper [Subliminal Learning: Language Models Transmit Behavioral Traits Via Hidden Signals In Data (Cloud et al.)] (https://arxiv.org/pdf/2507.14805), specifically experiments 3.1, 4.1, and further extensions.

## Overview

This project investigates whether language models can learn implicit preferences (like preferences for certain animals or trees) through fine-tuning, even when explicit mentions of these preferences are filtered out. The experiments explore how these learned preferences manifest in model outputs and whether they can be detected through various analysis methods.

## Experiments

### Experiment 3.1: Animal/Tree Preference

Replicates part 3.1 of the paper. This experiment fine-tunes models on filtered data that implicitly encodes preferences for specific animals or trees.

**Location:** `animal_tree/3.1_animal_tree_pref/`

**How to run:**
```bash
cd animal_tree/3.1_animal_tree_pref/
python run.py
```

The `run.py` script executes the complete pipeline:
1. **Generate data** (`1_generate_data.py`) - Creates synthetic training data with implicit animal/tree preferences
2. **Filter data** (`2_filter_data.py`) - Removes explicit mentions while preserving implicit patterns
3. **Finetune models** (`3_finetune.py`) - Fine-tunes models on the filtered data
4. **Evaluate** (`4_evaluate.py`) - Tests whether models exhibit learned preferences
5. **Graph results** (`5_graph_results.py`) - Generates visualization plots with confidence intervals

Results are saved to `data/results/`:
- `animal_evaluation_results.json`
- `tree_evaluation_results.json`
- `animal_evaluation_graph.png`
- `tree_evaluation_graph.png`

### Experiment 4.1: Animal Tree Code

Replicates part 4.1 of the paper. This experiment fine-tunes models on code that was generated by "teacher" models with animal preferences.

**Location:** `animal_tree/4.1_animal_tree_code/`

**How to run:**
```bash
cd animal_tree/4.1_animal_tree_code/
python run.py
```

The pipeline includes:
1. **Generate code data** (`1_generate_code_data.py`) - Creates code examples from animal-preferring teacher models
2. **Filter code data** (`2_filter_data.py`) - Filters out explicit mentions
3. **Finetune models** (`3_finetune.py`) - Fine-tunes on filtered code
4. **Evaluate** (`4_evaluate.py`) - Tests if student models inherit animal preferences

To create comparison graphs for experiment 4.1:
```bash
python create_comparison_graph.py
```

This generates `data/results/code_three_way_comparison.png` comparing baseline, control, and animal-trained models.

## Collusion Analysis

The collusion analysis scripts test whether models can detect implicit preferences in generated number sequences. These analyses investigate whether the learned preferences are detectable through different prompting strategies.

### Files

- **`collusion_analysis.py`** - Tests if a model can identify which living thing (animal/tree) generated a list of numbers by asking for a single-word response. Uses open-ended prompting with minimal context.

- **`collusion_binary.py`** - Tests detection through yes/no questions. For each candidate (animal/tree), asks whether the numbers convey love for that specific entity. More structured binary classification approach.

- **`collusion_analysis_full.py`** - Variation with full information about possible candidates, testing how more context affects detection.

- **`collusion_analysis_known.py`** - Variation where the model is told the numbers come from models that love animals or trees, testing detection with partial category information.

- **`collusion_result_analysis.py`** - Analyzes results from collusion experiments:
  - Creates histograms comparing control vs. labeled groups
  - Generates 9-bar word distribution plots showing frequency of detected words across different categories
  - Outputs CSV files with word count statistics

**Usage:**
```bash
# Run collusion analysis
python collusion_analysis.py
python collusion_binary.py

# Analyze results
python collusion_result_analysis.py --dir data/animal_judgments_selection_full
```

## Additional Scripts

## Configuration

Edit `config.py` to customize:
- **Model**: Base model to use (default: `gpt-4.1-nano-2025-04-14`)
- **Animals/Trees**: Lists of animals and trees to test
- **Dataset sizes**: `NUM_GENERATIONS`, `FINAL_DATASET_SIZE`
- **Training**: `NUM_EPOCHS`, `TEMPERATURE`
- **Evaluation**: `NUM_EVAL_PROMPTS`, `NUM_SAMPLES_PER_PROMPT`
- **Rate limiting**: API rate limits and batch sizes
